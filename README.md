# leotio-website

Statische Website der Leotio GmbH (leotio.com), gehostet über GitHub Pages.

- Reines HTML/CSS, keine Build-Tools, keine externen Ressourcen (DSGVO).
- Seiten: Start, Support, Impressum, Datenschutz.
- **Noch nicht live.** Vor Go-live: Platzhalter in Impressum füllen, `noindex`-Meta entfernen, `CNAME` mit `leotio.com` anlegen, Pages aktivieren, DNS bei Strato setzen.
